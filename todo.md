# Erfasst

## Offene Fehler und Verbesserungen

- Stream-Archiv: Eintrittszeit eines Zuschauers und die Spiele seiner Anwesenheit anzeigen.
- Earn Rules: Punkte muessen editierbar sein, inklusive sichtbarer IPC-/SQL-Fehler.
- Roulette: Konfigurierbare Pause bis zum Start der naechsten Runde.
- Duel: Allgemeine Statistik entfernen und den Verlauf als eine Zeile pro Duell anzeigen.
- Umfragen: Antworten im Bot und im Dashboard korrekt live anzeigen.
- Umfragen: Start aus einem gespeicherten Template reparieren.
- Roulette: Bei keiner Wette eine klare Meldung statt `0 von 0` ausgeben.
- Chat: Immer die neuesten Nachrichten anzeigen, ohne manuellen Scroll zu stoeren.
- Chat: Nachrichten auch ausserhalb der Dashboard-Ansicht empfangen.
- Werbung: Naechsten Werbezeitpunkt nicht als Jahr 1970 anzeigen.
- Roulette: Verlauf pro Runde als einen Gewinn-/Verlust-Eintrag statt als getrennte Buchungen anzeigen.
- Gamble: Cooldown zwischen Einsaetzen bzw. Runden ergaenzen.
